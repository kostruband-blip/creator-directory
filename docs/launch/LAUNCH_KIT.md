## 5. Google Search Console

1. https://search.google.com/search-console → **Добавить ресурс** → **«Ресурс с префиксом в URL»** → `https://creator-directory-chi.vercel.app/`.
   Тип «Домен» не подойдёт: для `*.vercel.app` нельзя добавить DNS-запись.
2. Подтверждение, вариант А — **HTML-файл** (без моей помощи):
   - скачайте `googleXXXXXXXX.html`;
   - в репозитории на GitHub: **Add file → Upload files**, загрузите в корень → **Commit changes**;
   - через 1–2 минуты (когда Vercel опубликует сайт) нажмите **Подтвердить**.

   Вариант Б — **Тег HTML**: пришлите мне содержимое `content="…"` из тега `google-site-verification`, я добавлю его на сайт.
3. **Индексирование → Файлы Sitemap** → `sitemap.xml` → **Отправить**. Ожидаемо: 204 URL.
4. **Проверка URL** → вставьте и нажмите **Запросить индексирование** (до ~10 в день):
   - `https://creator-directory-chi.vercel.app/`
   - `https://creator-directory-chi.vercel.app/tools/koshorts-ai-studio/`
   - `https://creator-directory-chi.vercel.app/tools/opus-clip/`
   - `https://creator-directory-chi.vercel.app/tools/submagic/`
   - `https://creator-directory-chi.vercel.app/tools/elevenlabs/`
   - `https://creator-directory-chi.vercel.app/ru`
5. Через 3–7 дней смотрите отчёты **«Страницы»** и **«Эффективность»**.

То же можно сделать в **Bing Webmaster Tools** (https://www.bing.com/webmasters): там есть импорт из Google Search Console в один клик, а Bing питает поиск ChatGPT и DuckDuckGo.
