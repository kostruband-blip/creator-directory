# Как добавить карточку вручную

Без программ, прямо на сайте GitHub. Через ~2 минуты карточка появится на сайте.

## Шаги

1. Откройте `tools.json` в репозитории → иконка карандаша ✏️ (*Edit this file*).
2. Нажмите **Ctrl + F** и найдите строку-якорь своей категории (таблица ниже), например `"id": "submagic"`.
3. Поставьте курсор **в начало строки с `{` прямо над ней** и вставьте шаблон (он заканчивается на `},` — запятая нужна).
4. Замените значения на свои.
5. **Commit changes…** → **Commit changes**.
6. Готово: workflow *Rebuild site after manual edit* проверит файл и обновит SEO, Vercel опубликует сайт.

| Категория | Ищите строку |
| --- | --- |
| Shorts и клипы (`shorts`) | `"id": "opus-clip"` |
| Субтитры (`captions`) | `"id": "submagic"` |
| ИИ-дубляж и голос (`dubbing`) | `"id": "elevenlabs"` |
| Превью (`thumbnails`) | `"id": "canva"` |
| Аналитика (`analytics`) | `"id": "vidiq"` |
| Telegram (`telegram`) | `"id": "tgstat"` |

## Шаблон

```json
    {
      "id": "my-tool-name",
      "name": "My Tool Name",
      "category": "captions",
      "featured": false,
      "pricing_type": "freemium",
      "pricing_en": "Free plan; paid from $10/mo",
      "pricing_ru": "Бесплатный тариф; платные от $10/мес",
      "pricing_uk": "Безкоштовний тариф; платні від $10/міс",
      "desc_en": "What problem the tool solves and for whom. Second sentence with the key benefit.",
      "desc_ru": "Какую задачу решает сервис и для кого. Второе предложение с главной выгодой.",
      "desc_uk": "Яке завдання розв'язує сервіс і для кого. Друге речення з головною перевагою.",
      "tags": ["captions", "tiktok", "reels"],
      "url": "https://example.com/",
      "tg": "https://t.me/ExampleBot",
      "added_at": "2026-11-25"
    },
```

## Правила полей

| Поле | Правило |
| --- | --- |
| `id` | уникальный, только `a-z`, `0-9` и дефис: `my-tool-name` |
| `category` | `shorts` · `captions` · `dubbing` · `thumbnails` · `analytics` · `telegram` |
| `featured` | `true` — золотая рамка и место вверху (платный Top-3), иначе `false` |
| `pricing_type` | `free` · `freemium` · `paid` (по нему работает фильтр цены) |
| `pricing_*` | до 80 символов |
| `desc_*` | 40–420 символов, 2–3 предложения. **В `desc_en` и `pricing_en` — ни одной русской/украинской буквы** |
| `tags` | 3–7 слов, маленькие латинские буквы |
| `url` | начинается с `https://` |
| `tg` | необязательно — если бота нет, **удалите всю строку** |
| `added_at` | дата `ГГГГ-ММ-ДД` |

Необязательный бейдж (например, для Fast-Track) — добавьте три строки после `"featured"`:

```json
      "badge_en": "Verified",
      "badge_ru": "Проверено",
      "badge_uk": "Перевірено",
```

## Частые ошибки

- **Пропущена или лишняя запятая.** Между карточками `},`, после последней строки внутри карточки (`"added_at": "…"`) запятой нет.
- **Кавычки «ёлочки» или ” ”** вместо обычных `"`.
- **Удалили строку `tg`, а запятая осталась у строки выше** — это нормально, если ниже идёт `"added_at"`; запятая нужна у всех строк, кроме последней.
- **Такой сайт уже есть** — валидатор не пропустит дубль домена или названия.

Если что-то не так, во вкладке **Actions** у запуска *Rebuild site after manual edit* будет красный крестик, а в шаге *Validate tools.json* — понятный список проблем, например `my-tool: 'desc_en' contains Cyrillic characters`. Исправьте и закоммитьте ещё раз. Пока ошибка не исправлена, сайт показывает последнюю сохранённую версию карточек.
